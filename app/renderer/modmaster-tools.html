Guided permission setup
ModMaster can grant itself access automatically (needs admin), or you can do it manually.
1
Close the game and the Xbox app.So no files are locked while we set permissions.
2
Grant ModMaster access to the game folder.Takes ownership + full control of the protected WindowsApps folder.
3
Install the tool.Same as any other game once access is granted.
Manual (run PowerShell as Administrator): takeown /f "<game folder>" /r /d y icacls "<game folder>" /grant "%USERNAME%":(F) /t Then re-run the installer and choose "Skip — try installing".
